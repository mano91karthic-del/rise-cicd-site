☕ Cozy Coffee – Futuristic Café Website

A modern, single-page café website built as a portfolio-grade project and a fake-but-believable startup MVP.
Designed to demonstrate frontend engineering, product thinking, and CI/CD readiness — without using heavy frameworks.

📌 Project Overview

Cozy Coffee is a futuristic café website that simulates real-world business behavior using pure HTML, CSS, and JavaScript in a single file.

This project focuses on:

Clean UI/UX

Realistic user interactions

Persistent client-side state

Deployment simplicity (perfect for CI/CD pipelines)

✨ Features
🕒 Live Business Status

Automatically shows OPEN / CLOSED based on local time

Simulates real café working hours (8 AM – 10 PM)

🧠 Persistent User Memory

Stores reservations using localStorage

Greets returning users automatically

📅 Table Reservation System

Simple reservation flow

Data persists across page reloads

📋 Interactive Menu

Modal-based menu with real pricing

Clean, distraction-free UX

🎨 Modern UI

Dark futuristic theme

Responsive layout (mobile-friendly)

Smooth scrolling and micro-interactions

⚡ CI/CD Ready

Single static file (index.html)

No build step

Works with GitHub Pages, GitLab Pages, Netlify, etc.

🛠️ Tech Stack
Technology	Usage
HTML5	Structure
CSS3	Styling & responsive design
JavaScript (Vanilla)	Logic & interactivity
localStorage	Client-side persistence
Git + CI/CD	Automated deployment

❌ No frameworks
❌ No dependencies
✅ Lightweight & fast
